# 🛍️ SmartPick AI — AI-Powered Product Recommendation System

A modern, responsive e-commerce web application built with **React** and **Tailwind CSS** that integrates an **AI-Powered Recommendation Engine** to analyze natural language user preferences (e.g. *"I want a phone under $500"*, *"Best laptop for coding with long battery"*) and filter, rank, and explain product recommendations in real time.

---

## 🌟 Key Features

1. **Natural Language Preference Understanding**:
   - Accepts complex user queries with budget thresholds, category requests, use cases, and feature constraints.
   - Quick-try prompt suggestions chips for instant evaluation.

2. **Dual-Mode AI Recommendation Engine**:
   - **Live External AI API**: Full integration with **OpenAI (GPT-4o mini / GPT-3.5-turbo)**, **Groq**, or any OpenAI-compatible API endpoint.
   - **Built-in Zero-Config NLP Engine**: Works immediately out-of-the-box without requiring an API key. Accurately evaluates budget constraints, category intents, and feature keywords with transparent AI reasoning badges.

3. **In-App API Configuration**:
   - Built-in **Settings Modal** to configure provider, paste API keys, select models, and run live test connection pings.
   - Keys are stored securely in browser `localStorage`.

4. **Product Catalog & Dynamic Filtering**:
   - 16 diverse, realistic products across Smartphones, Laptops, Audio, Wearables, and Accessories.
   - Filter switch: view **Filtered AI Recommendations** or browse **Entire Catalog with AI Badges**.
   - Category filter pills, price sorting, and rating filters.
   - Explanatory callout on each recommended card: *"Why AI Recommends This"*.

5. **Clean & Modern UI**:
   - Responsive design with Tailwind CSS.
   - Visual feedback, animated loading states, wishlist toggle, and "Add to Cart" interactions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended, tested on Node v22)
- npm (v9+)

### Installation
```bash
# Clone or navigate to the project directory
cd assessment

# Install dependencies (already pre-installed)
npm install
```

### Running the Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173` (or the URL displayed in the terminal).

### Running Automated Recommendation Engine Tests
```bash
npm test
```
Runs unit test suite verifying category parsing, budget ceiling compliance, and ranking logic.

### Building for Production
```bash
npm run build
```

## 💡 How to Test the Recommendation System

### 1. Test Without an API Key (Zero Setup)
Simply launch the app and try the following queries in the input box:
- `I want a phone under $500` *(Filters out high-end phones and non-phone items, returns Pixel 7a, Galaxy A54, and OnePlus Nord)*
- `Lightweight laptop for coding with long battery life` *(Recommends MacBook Air M2)*
- `Best noise cancelling headphones for travel and flights` *(Recommends Sony WH-1000XM5 and Anker Soundcore Space One with ANC)*
- `Affordable fitness tracker under $100` *(Recommends Xiaomi Smart Band 8)*

### 2. Test With Your OpenAI / Groq API Key
1. Click the **API Settings** button in the top navigation bar.
2. Select your provider (**OpenAI** or **Groq**).
3. Paste your API key (e.g. `sk-...`).
4. Click **Test API Key** to verify connectivity.
5. Click **Save Settings**.
6. Enter any custom query to receive live recommendations generated by GPT-4o mini!

## 🏗️ Project Architecture

```
assessment/
├── index.html                 # HTML shell and metadata
├── vite.config.js             # Vite configuration with React plugin
├── tailwind.config.js         # Tailwind CSS styling configuration
├── postcss.config.js          # PostCSS configuration
├── package.json               # Dependencies and scripts
├── test-engine.js             # Automated test suite for recommendation engine
└── src/
    ├── main.jsx               # Application entry point
    ├── index.css              # Tailwind base, components, and utilities
    ├── App.jsx                # Core app state, layout, and filtering pipeline
    ├── data/
    │   └── products.js        # Rich product catalog with specs, categories, tags
    ├── services/
    │   └── aiService.js       # AI API client (OpenAI) & built-in NLP engine
    └── components/
        ├── Navbar.jsx         # Header with branding and live AI status badge
        ├── PreferenceInput.jsx# Search box with AI spark and prompt suggestion chips
        ├── RecommendationSummary.jsx # AI summary, confidence, and explanation banner
        ├── ProductCard.jsx    # Card with AI pick rank and "Why AI Recommends" box
        ├── FilterBar.jsx      # Category pills, inline search, and sort options
        └── SettingsModal.jsx  # API key, provider selection, and connection tester
```
